# 片场 Fieldwork · 个人 AI 创作室

打开首页，写下一句话即可生成剧本、分镜或口播文案。也可以把几段自己拍的视频拖进输入框，让模型参考画面和逐字稿创作。发送第一条要求时会自动建立对话。

- 在作品下方选择「直接编辑」修改原稿，或继续对话生成下一稿。上传的素材和完成的作品都会出现在「我的资产」。
- 每段对话有一张素材画布。素材引用和续写关系自动连线，也可以拖动卡片、手动连线。
- 展开「创作工具」即可使用声音克隆、配音和抖音文案提取。项目历史、客户审核与交付从侧栏底部的「历史项目管理」进入（`/archive`）。
- 每个部署是一间个人创作室，以站点访问口令保护。设置 `AI_*` 可生成文本，设置 `VISION_*` 可参考视频画面。未配置模型时会显示本地示例。

右上角的太阳或月亮可切换暗色与明亮主题，同一浏览器会记住选择。首页、对话、画布、资产、工具、历史项目和客户审核共用这套外观。[查看全部页面的 GPT Image 双主题设计稿](docs/design/README.md)。

## Docker 一键运行

```bash
cd ~/Code/merchant-content-hub
node scripts/setup-env.mjs
docker compose up -d --build
```

打开 <http://127.0.0.1:3100>。部署包含 Next.js 网页、Fastify API 和 PostgreSQL 三个服务。媒体卷和 PostgreSQL 卷独立保存，原有 SQLite 可自动一次性导入。[后端架构、迁移与开发说明](docs/FASTIFY_POSTGRESQL.md)。

如需真实 AI / ASR 或团队访问口令，填写 `.env` 后执行 `docker compose up -d api web`。也可统一使用包含数据库口令的 `.env.local`，配合 `--env-file .env.local`。配置、日志、备份、端口与容器验收见 [DOCKER.md](DOCKER.md)。

## 本机开发运行

环境：Node.js **24.11+**、npm。视频探测 / 缩略图 / 粗剪与真实 ASR 音轨提取需要 `ffmpeg` 和 `ffprobe` 在 PATH 中。

```bash
cd ~/Code/merchant-content-hub
npm ci
npm run setup
# 启动独立开发数据库，不替换正式 Docker 容器
docker compose -p merchant-content-hub-dev -f compose.yaml -f compose.dev.yaml up -d db
PORT=3200 API_PORT=3201 DATA_DIR=./data/dev npm run dev
```

开发实例打开 <http://127.0.0.1:3200>，正式 Docker 仍为 3100。默认仅绑定本机；PostgreSQL 由本地 Compose 提供，不需要云数据库、OSS 或 AI 账户即可体验演示流程。

生产构建方式（本地运行）：

```bash
npm run build
npm start
```

不显式配置端口时，本机服务默认使用网页 3100 和 API 3101，启动前应确认端口可用。默认首次启动自动建立两家**虚构示例商家**、两个项目及演示素材。演示素材没有实际媒体文件，不能预览或粗剪。已有数据不会被重复初始化或覆盖。

如需空白数据库，在首次启动前复制 `.env.example` 为 `.env.local`，设置 `SEED_DEMO=false`。这只控制初始化，不会删除已有演示或业务数据。

## 可以做什么

| 工作环节 | 本版能力 |
| --- | --- |
| 商家与项目 | 商家定位 / 客群 / 品牌风格；拍摄交付或代运营；服务费、交付数量、截止日期与目标 |
| 素材库 | 拖拽 / 点击多文件上传、分次追加与待上传列表移除，视频 / 音频 / 图片 / TXT / SRT / MD；私有文件保存，缩略图、时长、标签、授权与有效期 |
| 转写索引 | 已授权音视频上传后自动后台转写，显示队列与结果状态，不阻塞其他工作；无凭据可导入人工逐字稿和 SRT；时间码点击定位播放 |
| 素材检索 | 名称 / 标签 / 逐字稿与同义词检索，按素材分组显示命中片段，点击定位原片；支持明确返回列表、类型过滤与旧请求取消；排除未授权和过期素材 |
| 内容创作 | 手动选择参考素材（可切自动） + 商家资料 → 选题、脚本、平台文案与话题；保留素材引用；支持抖音 / 小红书 / 视频号 |
| 拍摄执行 | 任务说明、负责人、日期、重点镜头与完成勾选；适配手机 |
| 客户审核 | 独立手机友好审核页，查看脚本、文案和关联成片；通过 / 修改意见；版本与审核记录 |
| 交付与运营 | 拍摄交付：审核通过后确认交付；代运营：审核后设置北京时间排期、手动发布确认；导出已审核的 JSON 交付清单 |
| 实际粗剪 | 对真实视频指定起止秒数，FFmpeg 转码导出 MP4，最多 60 秒 / 次；产物回到素材库，可关联到待审核内容 |

**本地检索是关键词 + 同义词算法，不是向量语义检索。** 本版粗剪是单片段截取，不是自动多镜头剪辑、去口误、自动配乐或精剪。

## 清理内容草稿

AI 创作台的每条草稿提供“删除草稿”，列表顶部支持勾选、多选与“删除所选”。确认框列出本次要删除的标题，确认后永久删除对应内容记录，关联原始素材、成片和文件继续保留。

仅 `草稿` 与 `待修改` 可删除，审核中、已通过、已交付、已排期或已发布内容受到保护。每次最多 200 条，接口核对项目归属和内容版本；批量中有记录发生变化会整体拒绝，避免部分误删。本版尚无回收站。

## 在历史项目管理中体验交付流程

1. 在顶部选择「青野咖啡」代运营示例项目，浏览工作概览。
2. 在素材库搜索「老板的开店故事」，查看演示时间码与来源标记。
3. 上传真实视频，确认授权；在素材详情导入 SRT 或填写逐字稿并保存。
4. 输入开始和结束秒数，生成粗剪；返回素材库下载 MP4。
5. 在 AI 创作台生成草案并编辑，选择来源素材和最终成片。
6. 提交审核，打开客户链接；在客户页提出修改意见或确认通过。
7. 拍摄项目确认交付；代运营项目设置未来排期，到时手动发布并确认。导出交付清单。

保存修订会新增版本、回到草稿、取消原排期并撤销旧审核链接；需要重新提交审核。审核链接有效期为 7 天，持有链接者可查看该单份内容及关联媒体，应只交给对应客户。脚本未关联成片时，页面会明确提示只审核文案稿。

## 接入真实 AI / ASR

当前提供 DeepSeek Flash 预配置：`AI_BASE_URL=https://api.deepseek.com`、`AI_MODEL=deepseek-flash`。本机项目 `.env` 已填好这两项，`AI_API_KEY` 留空；填写你自己的 DeepSeek Key 后执行 `docker compose up -d web` 即可应用，无需重新构建镜像。Compose 自动读取项目 `.env`。本机开发方式在修改后重启服务。

配置参考：[DeepSeek 官方接入说明](https://api-docs.deepseek.com/quick_start/agent_integrations/)。已用实际 Key 通过业务接口完成联调，约 13.7 秒生成 3 条选题、脚本和文案；输入为演示素材。当前 DeepSeek 请求用于选题、脚本和文案，只发送文字；图片理解链路尚未实现。百炼 ASR 已另行完成真实账号联调。

```bash
cp .env.example .env.local
```

编辑本地配置，重启服务；不要提交 `.env.local` 或密钥。

```dotenv
# 兼容 POST /chat/completions 的服务，地址包含供应商要求的版本前缀，例如 /v1
AI_BASE_URL=
AI_API_KEY=
AI_MODEL=

# 百炼文件转写：Key 与地址须属于同一地域，以下为北京
ASR_WORKER_ENABLED=true
ASR_PROVIDER=aliyun
ASR_BASE_URL=https://dashscope.aliyuncs.com/api/v1
ASR_API_KEY=
ASR_MODEL=qwen-audio-3.1-asr-flash-filetrans
ASR_TIMEOUT_SECONDS=180
```

AI 三项齐备才启用真实接口，否则显示「本地演示模板」。真实接口调用失败会提示错误，**不会静默切换为演示结果**。ASR 未配置时不会编造音频内容；请使用人工逐字稿 / SRT。DeepSeek Flash 文本链路已完成实际账号调用验证；百炼 ASR 已通过短合成录音的真实接口验证，真实商家现场素材的准确率仍待业务验收。费用和模型支持范围由所选供应商决定。

在「素材资产库」上传视频或音频并确认授权后，系统自动加入后台转写队列，无需点击转写按钮。上传接口不等待识别，可以切换页面、继续建任务或关闭浏览器；卡片和详情显示排队 / 处理中 / 完成 / 失败状态。待确认素材在保存授权后自动排队；无音轨视频跳过，图片和文稿不调用 ASR。

完成后自动保存逐字稿与时间码，点击片段即可定位播放。词级时间与说话人保存在 `segments[].words` / `speakerId`。只改标签和备注会保留这些数据；保存人工逐字稿会停止后台任务覆盖。自动刷新也会保留详情中尚未保存的编辑内容。

百炼适配先用 FFmpeg 提取完整的单声道 16kHz FLAC（不删除静音、不改变时间轴），提取音轨上限 128 MB。使用同一 ASR Key 获取临时上传凭证、上传音轨、提交异步任务、查询并下载 JSON；无需自备 OSS Key。API 返回的毫秒统一转换成秒保存。临时音轨在百炼存储 48 小时后自动清理，本地转换副本完成或失败后删除；原始媒体仍在私有数据卷。临时上传是本地 MVP 方案，正式生产和大批量使用需改为自有 OSS 与签名 URL。

队列和远端任务编号保存在 PostgreSQL。Fastify 服务启动后自动运行后台 Worker，使用原子抢占和租约防重；服务重启后继续处理队列，已取得百炼任务编号时查询原任务。浏览器只刷新状态，不执行识别。该实现适用于当前持续运行的本机 / Docker 服务，尚未作为 Serverless 或跨主机分布式队列交付。

`ASR_TIMEOUT_SECONDS` 控制后台单轮查询窗口，默认 180 秒，范围 15–600 秒。超时后继续查询有效任务；已知任务的网络查询错误最多退避重试 3 次。确定失败后可在详情点击「重试转写」，接口立即返回 HTTP 202，只重新排队。提交未确认且没有任务编号、任务超过 23 小时或服务配置变更时，不自动重新提交收费请求，等待明确重试。

`ASR_WORKER_ENABLED=false` 可暂停 Worker，默认开启。不会批量处理历史未转写素材；之前已提交的百炼任务会恢复。无需 Redis，正式大规模处理可迁移至独立媒体 Worker。

原通用转写服务仍可配置 `ASR_PROVIDER=openai`，地址使用供应商的版本前缀，调用 `/audio/transcriptions`（`verbose_json`）。该路径提取 WAV，上限 24 MB，接口等待上限 90 秒；供应商仅返回文字时不会虚构时间码。

接口参考：[百炼文件转写](https://help.aliyun.com/zh/model-studio/qwen-audio-asr-filetrans-http-api)、[百炼临时文件上传与限制](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)。

## 独立视频旁白

直接打开 `/narration`，或从工作台导航进入。选择已保存的个人音色并上传视频后，系统自动理解画面、生成带时间区间的分镜旁白并制作第一版 MP4。没有原声的视频也可使用，不依赖商家、项目、素材库或已有逐字稿。

支持 MP4 / MOV / WebM，2 秒至 10 分钟，文件大小沿用 `MAX_UPLOAD_MB`（默认 128 MB）。FFmpeg 检测转场并将连续长画面划为不超过约 12 秒的讲述区间，最多 60 段，每段提取前后两张有时间标记的画面；图像经服务端发送至云端视觉模型。镜头边界来自视频处理，模型只返回画面描述和旁白，不直接决定剪辑时间。默认模型为当前账号已验证可用的 `qwen3.8-flash`，关闭思考模式以控制延迟和消耗；语音继续使用个人音色绑定的 CosyVoice 模型。没有新增本地推理框架或模型权重。

画面分镜与旁白段落独立，一句话可跨多个镜头。点击旁白定位画面，支持合并下一段、拆为两段、删除、调整参考时间和逐段修改语调、情感与语速；展开画面参考可查看本段覆盖的镜头。清空文案则不合成本段声音。未提交修改自动保存在当前浏览器，点击「保存旁白」保存到服务端但不触发配音。「试听本段旁白」使用临时语音接口，点击「保存修改并生成成片」才创建新版本，已有 MP4 不会被覆盖。旧分镜文案和草稿自动兼容为旁白段落。相同账户、模型、音色、文字和有效表达的已完成片段可持久化复用，单纯调整原声音量无需重做语音。

字数只作为整片创作建议，不按单个镜头硬性拦截。去掉配音文件自带的首尾静音后，按实际声音长度安排时间；切换画面时声音可继续，片头、段间与片尾每处留白不超过 2 秒。优先保留自然语速与合理起点，必要时统一适度放慢（最低 0.85 倍）或加快（最高 1.35 倍）；文案仍过短时明确提示补充，不靠极慢朗读或挪动大段静音填满视频。累计声音超出容量时暂停后续语音请求。已完成片段会保留，重新安排时间不重复合成。字幕使用成片中实际朗读时间。原视频声音默认关闭，可按比例混入；它包含原有对话、音乐和环境声，不是人声分离功能。支持浏览器成片预览、MP4 下载及 VTT 字幕下载，MP4 同时包含软字幕轨。输出最长边不超过 1280 像素，保持原镜头顺序和时长。

双语字幕默认中文在上、英文在下，白字黑描边，按短句显示并写入预览和下载的 MP4。生成时通过现有 `AI_BASE_URL` / `AI_API_KEY` / `AI_MODEL` 自动翻译缺少的短句译文，使用独立翻译提示词，仅发送旁白文字；每句译文可以修改并保存在本机草稿。只改译文或字幕样式可复用已有配音。修改原文后，保留仍对应原短句的译文，其他短句会在生成时补译。译文与原文绑定，已确认结果可跨重启复用；未知翻译提交不会自动重提。

双语成片同时提供无字幕版本，以及中文、英文和双语 SRT 下载，供后期剪辑使用。写进 MP4 画面的字是像素，不能直接作为文字修改；使用无字幕成片加 SRT，导入支持字幕的剪辑软件后可编辑文字与时间、重新设置字体位置。SRT 不包含本工具的完整排版样式。无字幕版本只去掉本工具新增的旁白字幕，原视频已有的文字仍会保留。段内字幕时间按短句文本权重分配，沿用实际配音段落起止时间，不等同于逐字 ASR 对齐。旧成片不改动，需创建新版才带双语字幕。

配置 `VISION_API_KEY` / `VISION_BASE_URL` / `VISION_MODEL` 可使用独立兼容视觉服务；前两项为空时复用 `ASR_PROVIDER=aliyun` 的 Key 与地址，并转换至 `/compatible-mode/v1`，不使用 DeepSeek 的商家策划提示词。`NARRATION_WORKER_ENABLED=false` 可停止此功能的后台处理。模型 Key 只进入 API 容器；画面理解和配音会产生相应云服务用量。上游结果不确定时保留提交状态，不自动重复收费，需手动重试。

本机执行双语视频渲染与相关浏览器测试时，FFmpeg 需包含 libass（`ass` 滤镜）并安装中文字体；Docker API 镜像已内置这些依赖。精简版宿主 FFmpeg 会跳过双语像素测试，完整验收应使用带字体的运行环境。

验证命令：`npm test`、`npm run test:narration`（系统 Google Chrome）、`npm run test:narration:postgres`（独立 PostgreSQL 和容器重建）。

## 个人音色与配音

制作中的草稿会自动保存在当前浏览器的本机存储，切换页面或刷新后恢复名称、文案、音色选择、视频来源、全篇表达及逐句标记。不会保存尚未提交的文件、录音 Blob、麦克风授权或确认勾选。清除浏览器站点数据会移除草稿；本机存储不可用时会提示，仍可继续编辑和生成。

音色卡片支持「删除音色」，确认后清理保存的录音和对应服务音色，已完成的配音继续保留并可播放下载。创建中的音色、正在被配音任务使用的音色需等待完成；删除后无法再用它生成或重试配音。服务端删除由持久化后台任务处理，失败保留记录并提供「重试删除」，已确认云端删除后可继续完成本地清理；仅有本地样本时不需要语音凭据即可删除。

输入文案后切换「逐句表达」，自动按中英文句子拆分。每句默认跟随全篇，可单独覆盖语调、情感（含轻松自然）、语速、音高，并在原有自然停顿后额外增加 0.2～3 秒停顿。选中本句文案中的光标位置可拆分，也可与下一句合并；合并保留当前句表达和原下一句的句后停顿。整篇编辑仍保留逐句设置，未改的句子保留标记，改写部分重新分句并继承全篇。全文最多 2000 字符、60 句，每句最多 500 字符。

逐句模式提供「试听本句」和「连听前后句」，按所选句子读完（一次试听最多 600 字符）；仍保留开头约 5 秒试听。试听不写正式记录或媒体。完整生成与逐句试听使用同一份有效设置和同一个分段合成流程，相同音色、模型、文案和有效表达的片段在 API 内缓存 10 分钟，最多 32 份 / 32 MB；修改无关句子不影响本句试听，单纯修改停顿可复用原片段。进程重启或缓存过期后需重新合成试听。

每个完整分段任务持久化已完成片段、已知下载地址和提交标记，失败重试仅继续未完成部分；未知收费提交不自动重提。合成结果统一解码为 24 kHz 单声道后拼接，消除逐段 MP3 编码填充，插入停顿后导出一个 MP3。已完成任务清理中间片段，失败任务保留以便恢复；全篇与每句设置随历史记录保存，不新增商家或项目依赖。情感和重音通过 CosyVoice 指令引导，实际效果需试听确认。

逐句浏览器验收：`npm run test:dubbing:sentences`，覆盖分句、拆分合并、局部表达、无关改动不清除本句试听、前后句试听、正式生成复用片段和手机布局。

「添加音色」默认支持直接在网页录音：点击「开始录音」并允许麦克风，停止后试听或重新录制，确认后保存为音色。录音至少 5 秒，推荐 10～20 秒，满 60 秒自动停止；停止、取消或关闭弹窗都会释放麦克风。也可切换「上传录音」使用已有文件。麦克风需要 HTTPS 或本机 `localhost` / `127.0.0.1` 地址；权限拒绝、设备不可用或浏览器不支持时会显示相应提示。

网页录音先在浏览器内转为单声道 24 kHz WAV，只在点击「保存并创建音色」后提交，进入音色创建队列。系统 Chrome 的模拟麦克风验收覆盖原生 MediaRecorder 采集、权限拒绝、取消释放、短录音、重录试听、WAV 保存及后续配音；实际设备的收音质量由用户试听确认。实现参考：[getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)。

在工作台侧栏打开「声音克隆与配音」（旧地址 `/dubbing` 会跳转到该栏目），上传自己的 WAV / MP3 / M4A 朗读录音，保存音色后可以重复使用。单份录音不超过 10 MB，时长 5～60 秒，推荐 10～20 秒清晰、无音乐的单人朗读。录音在本地私有媒体卷保存，创建音色时发送给百炼。音色可在工作台跨项目复用。选择项目后，新配音、本地视频转写与配音草稿按项目保存。无归属的旧记录仍可使用，空白项目草稿可手动载入旧版本机草稿。可直接填入项目脚本或已授权素材的逐字稿，完成的 MP3 和转写文稿可存入项目素材库并确认授权。当前使用站点级访问口令，不提供个人账号隔离。

文案支持直接输入 / 粘贴，或在工具内上传音视频并等待后台转写，点击「使用此文案」后人工校对。保留原文语言，不自动翻译；单次最多 2000 字符，长稿分段生成。选择个人音色和语速后，先点击「试听前5秒」检查开头，合适后点击「生成完整配音」保存正式记录并下载 MP3。重播已有音频或下载不会再次调用语音合成。

生成前试听只发送开头一小段文案，并把返回的音频裁剪为最多约 5 秒。试听不会进入配音记录或素材库，无需手动删除；修改文案、音色或任何表达设置后会停止并清理旧试听。同一段的「再听一次」直接在浏览器播放，相同开头、音色及全部表达设置的预览在 API 内缓存 10 分钟。新的试听仍会消耗少量语音额度。临时音频在返回后删除，缓存到期自动释放，正式配音仅在点击完整生成时保存。

「表达设置」支持自然朗读、日常聊天、讲述故事、清晰播报和重点强调等语调，以及温暖、开心、平静、严肃、悲伤、兴奋等情感，并提供 0.9 / 1 / 1.1 倍的音高微调。音色、语速、语调、情感与音高组成同一套设置，试听和完整生成共用；修改任一表达选项都会停止旧试听，并按新的设置匹配预览缓存。完整配音记录保存所有设置，失败重试沿用原值，历史记录缺少新字段时按自然表达与原始音高兼容。

语调与情感使用 CosyVoice 复刻音色的自然语言指令控制，效果由模型引导，应先试听确认；音高主要调整声音高低。当前支持此类表达控制的模型为 `cosyvoice-v3-flash`、`cosyvoice-v3.5-flash`、`cosyvoice-v3.5-plus`；其他模型的音色保留语速和音高调节，界面禁用语调 / 情感选项，接口也会在收费请求前校验。

```dotenv
TTS_WORKER_ENABLED=true
TTS_API_KEY=
TTS_BASE_URL=
TTS_MODEL=cosyvoice-v3-flash
```

当 `ASR_PROVIDER=aliyun` 时，空的 `TTS_API_KEY` / `TTS_BASE_URL` 会复用现有百炼 ASR 凭据与地址；也可独立配置同地域语音服务。新业务空间可使用 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1`。音色创建与语音合成都由 Fastify 调用，密钥不传给前端。凭据未配置时仍可保存样本，配置后继续创建音色；服务错误不会伪装成成功音频。更换 Key 或服务地址后，已有音色需要恢复原配置或重新创建；更换默认模型不影响原模型绑定音色。

音色创建与配音使用 PostgreSQL 持久化后台任务，关页后继续。已保存的音色编号和音频结果地址可恢复查询 / 下载；若进程中断时无法确认收费请求结果，任务会失败并等待手动重试，避免自动重复收费。结果链接失效时会明确提示，手动重试将重新合成。最终音频下载到私有媒体卷后长期保存，不依赖供应商临时链接。

验证命令：`npm test`、`npm run typecheck`、`npm run build`、`npm run test:dubbing`、`npm run test:dubbing:preview`、`npm run test:dubbing:postgres`。配音浏览器验收使用系统 Google Chrome、隔离数据和本地模拟服务，覆盖零商家零项目直接使用、音色保存、两种文案来源、后台执行、试听下载及手机布局；2026-11-07 另使用百炼官方公开示例录音完成真实音色创建、中英文配音、视频转写和再次配音，并将生成音频重新转写核对中英文内容；测试音色已删除。本人音色相似度仍需使用自己的录音试听确认。

接口依据：[百炼声音复刻 HTTP API](https://help.aliyun.com/zh/model-studio/voice-clone-design-http-api)、[CosyVoice 非实时语音合成 HTTP API](https://help.aliyun.com/zh/model-studio/cosyvoice-tts-http-api)。

## 创作参考素材与实际引用

创作台默认「手动选择」。勾选 1–30 份本项目已授权、未过期的素材后才能生成；只有勾选文件的名称、标签与已有文字进入 AI 请求。未勾选的素材不会参与，空选或失效选择也不会回退为全部参考。提供全选 / 选择前 30 份、清空和单份预览；手动列表包含全部可用文件，可以指定较早入库的素材。

需要沿用项目范围时可明确切换「自动参考」：按项目、授权和期限取最多 30 份，并不按主题相关性排序。切换项目重置为手动空选，新上传的文件不会自动加入手动范围；已选文件失效时阻止生成，移除失效选择后保留其他有效选择。

选材划定允许参考的范围，不要求每条文案使用所有所选素材。每条草稿单独保存并展示实际引用的素材名称，可以点击回看；最终成片在编辑草稿时另行关联。当前输入为名称、标签与已有转写 / 文稿文字，单份文字最多 3000 字符，不直接读取视频画面。

生成接口同样默认手动模式，调用 `/api/generate` 时通过 `referenceAssetIds` 指定素材 ID；使用自动模式须明确传 `referenceMode: "auto"` 并省略 ID 列表。服务端验证空选、重复、数量、归属、授权与期限，并在返回结果入库前再次复核已发送的全部素材。

## 数据与访问

- 正式数据库：PostgreSQL，由 `DATABASE_URL` 指定；媒体：`DATA_DIR/uploads/`。SQLite 只保留用于旧数据导入和显式隔离演示。
- 文件与数据库保存在服务端；重启应用后仍保留，不依赖浏览器本地记录。浏览器仅记录当前选择的项目。
- PostgreSQL 与媒体分别持久化；备份需同时保存 `pg_dump` 和媒体目录。旧 `hub.sqlite` 只保留为迁移时的回退副本，不包含切换后的新数据。操作见 [DOCKER.md](DOCKER.md)。
- 上传单文件默认 128 MB，可用 `MAX_UPLOAD_MB` 调整（1–512 MB）；这是小规模 MVP，不能承接几十 GB 原片。
- 仅设置 `HUB_ACCESS_TOKEN` 时启用团队共享访问口令，API 支持 Bearer；Web 登录后使用 HttpOnly Cookie。建议口令使用随机十六进制字符串。
- 没有商家独立账号、角色权限、SaaS 租户隔离或审计合规承诺。项目范围约束避免跨项目引用，但不代表多租户安全边界。
- 删素材只移除索引，磁盘文件保留供恢复；已被内容引用的素材无法删除。暂未实现磁盘文件清理策略。
- 客户链接在本机可打开；跨设备使用需部署可访问服务，并配置 HTTPS、身份权限及访问限制。不要直接将当前无账号版本暴露到公网。
- 内容日历只记录排期与团队确认；不会登录、爬取或自动发布到社交平台。

## 抖音链接文案提取

在首页侧栏展开「创作工具」并选择「抖音文案提取」，旧地址 `/douyin` 会跳转到该栏目。新提取记录跟随当前项目。可将当前版本的字幕存入项目素材库，保留原链接和时间码，在素材详情确认使用授权。粘贴抖音短链、移动端视频长链或完整分享文字，可在后台提取视频画面中的中文字幕；支持查看进度、保留记录、逐句校对、复制全文及下载 TXT / SRT。英语配音配中文字幕时提取原有中文字幕，不使用语音重新翻译。

当前支持 5 分钟以内、128 MB 以内的公开视频，可选择下方、中部或整幅画面作为字幕区域。识别结果先标为待校对；保存校对后，TXT 与 SRT 同步更新。抖音接口可能限流或变化，不保证所有链接可用；失败可手动重试。

该流程不使用浏览器、登录 Cookie 或付费模型。Docker API 镜像包含 Python、curl、FFmpeg 和 RapidOCR/ONNX Runtime 中文识别模型；macOS 直接开发时可使用系统 Swift/Vision。`DOUYIN_WORKER_ENABLED=false` 可暂停后台处理。队列保存在 PostgreSQL/SQLite 的 `douyin_extractions` 表，处理中的视频与帧仅用于识别，完成或失败后清理。
